# Bill 3.0.1 界面更新验证

## 改动

- 饼图各扇区通过引线直接连接完整分类名和百分比，移除下方占比图例。长名称换行，小扇区标签错开；仍支持点击分类筛选流水。
- 缩小首页留白、今日支出和预算摘要，今日支出与月支出横向排列，突出记账表单。
- 分类按钮使用不同填充色，选中时加深并显示勾选。旧账本重复颜色仅在界面中区分，不修改保存的分类或交易。
- 分类选择旁直接显示备注输入框，支持换行，保存及编辑时仍使用原备注字段。

## 验证范围

- `npm run check`：21 个单元测试、ESLint、TypeScript 和生产构建。
- `npm run test:mobile`：原有迁移、记账增改删、实时预算、账户转账、备份恢复、修正历史、重启、损坏数据恢复、深色模式、字号缩放；增加分类旁备注、不同底色、紧凑摘要、七分类直接标注、标注筛选及备注持久化。
- 320、393、430、768 像素宽度实测图表完整；长分类名、大量分类及小扇区的布局和引线避让另有测试。
- 独立代码审查已检查引线避开圆环中心，未发现剩余阻塞问题。
