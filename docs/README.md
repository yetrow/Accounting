## 文档维护约定

- 功能或数据结构改变时，同步更新相关说明；以仓库实现为依据。
- `docs/screenshots/` 仅保留人工选定、用于项目展示的图片，不放真实账本或个人信息。
- 自动测试截图写入 `test-results/screenshots/`；测试报告、日志和构建产物不提交。
- AI 工作计划、执行进度、会话记录和一次性的验证流水不作为正式项目文档提交。
- 测试指南说明如何验证及其覆盖范围；具体提交的执行结果以 GitHub Actions 为准。
