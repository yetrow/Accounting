# Bill Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 把 Ledger 2.0.3 重构为可迁移、可验证的 Bill 3.0.0。
**Architecture:** 平台无关领域核心，Repository 负责事务及审计，React 仅维护表单/导航状态。Android SQLite 为正式账本，IndexedDB 仅为浏览器适配。
**Tech Stack:** TypeScript, React, Node 24 node:sqlite, Android Java/SQLite, Gradle。
**Spec:** docs/superpowers/specs/2026-10-04-bill-design.md

## Global Constraints
- applicationId com.jizhang.repaired；显示名 Bill；3.0.0/300。
- 金额为整数分；本轮仅 CNY；禁止失败时静默初始化或回退。
- 同一事务包含投影、审计、版本和恢复点；旧 localStorage 保留。
- 私钥不入库；保留本地 HTTPS origin。

## Review Focus
- 旧数据损坏/混合版本：停止迁移、保留原始数据，不能空账本覆盖。
- 金额边界、日期、转账与引用：校验并拒绝无效写入；预算只统计支出。
- 并发写/中途异常：事务回滚、版本冲突，不丢一方数据。
- 导入后修正和恢复：历史保留、外键有效、恢复点可重复交换。
- 小屏/深色/字体缩放：全部分类占比可读，保存按钮不重复提交。
